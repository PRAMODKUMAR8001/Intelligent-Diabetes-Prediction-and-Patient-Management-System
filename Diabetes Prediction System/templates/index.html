Technical Insight

About This Project

This system is powered by a Logistic Regression machine learning classifier trained on the standard PIMA Indians Diabetes dataset. The model evaluates patient metrics such as glucose tolerance, BMI, insulin response, blood pressure, pedigree function, and age to classify the probability of diabetes.

A streamlined backend handles user database integrations, hashed password protection, dynamic line graphs using Chart.js, and appointments management, making it a reliable portal for early health screenings.
